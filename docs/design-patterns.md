# Design Patterns Inventory — Progressive Minie Shop

Living architectural catalog of every software and React design pattern actually implemented across the **Progressive Minie Shop** monorepo (`apps/storefront`, `apps/api`, and `packages/*`).

> **Maintenance Rule (Keep Updated As We Go):**
> Whenever a new design pattern is introduced, refactored, made consistent across modules, or retired during any phase or PR, update this document in the same change set. Only list patterns backed by concrete code in the repository; clearly distinguish deliberate patterns from ad-hoc implementations and intentional absences.

## 1. Frontend & React Design Patterns (`apps/storefront`)

| Pattern | Status | Location | Problem Solved | Assessment | Trade-offs |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Headless UI / Prop Getters & WAI-ARIA APG Controls** | Deliberate | `apps/storefront/src/hooks/useCombobox.ts`, `SearchBar.tsx`, `Dropdown.tsx`, `ProductDetailPage.tsx` (Tabs), `MiniCart.tsx` (native `<dialog>`) | Encapsulates WAI-ARIA APG keyboard navigation (`Arrow*`, `Home`, `End`, `Escape`), IME guard, focus restoration, and modal semantics without external UI framework lock-in (`ADR-0020`). | **Strong & Consistent.** `SearchBar`, `Dropdown`, PDP `Tabs`, and `<dialog>` `MiniCart` are verified by `vitest-axe` (mounted inside `RootLayout`) and Oxlint `jsx-a11y`. | Team owns APG edge-case maintenance; provides clean reference behavior for Phase 8 `@minieshop/ui` primitives. |
| **Composition-Root Provider / Dependency Injection** | Deliberate | `apps/storefront/src/main.tsx`, `apps/storefront/src/context/ProductRepositoryProvider.tsx`, `productRepositoryContext.ts`, `useProductRepository.ts`, `I18nProvider.tsx` | Injects `ProductRepository` (`HttpProductRepository` instantiated in `main.tsx`, `MockProductRepository` in tests) and reactive `en` / `pt-BR` locale without prop drilling or context-to-infra coupling. | **Clean & Enforced.** Concrete infrastructure is wired strictly in `main.tsx` and verified by Oxlint layer rules. | `I18nProvider` reads `window.localStorage` in initial `useState`, which will require SSR-safe hydration if migrating to Next.js. |
| **Repository Pattern + Separated Query Encoders** | Deliberate | `apps/storefront/src/domain/repositories/ProductRepository.ts`, `domain/errors.ts`, `infrastructure/repositories/{HttpProductRepository,MockProductRepository,queryStrings}.ts` | Decouples UI/hooks from `fetch`, HTTP query encoding, and transport error classes while giving tests an in-memory twin verified by `productRepositoryContract.test.ts`. | **Cleanly Layered.** HTTP `URLSearchParams` builders live in `infrastructure/repositories/queryStrings.ts` (including `?currency=` on `/search`), keeping `domain/` framework- and transport-free. | `ProductRepository` spans catalog, search, recommendations, favorites, and pricing; split by domain when Checkout/Identity UI arrives. |
| **Adapter Pattern (Search Client) behind Hook Facade** | Deliberate | `apps/storefront/src/infrastructure/search/instantSearchAdapter.ts`, `apps/storefront/src/hooks/useSearch.ts` (`useStorefrontSearchClient`), `SearchResultsPage.tsx` | Adapts `ProductRepository.searchProducts` (`GET /search`) to the `SearchClient` contract expected by `react-instantsearch` without coupling presentation pages to `infrastructure/` (`ADR-0019`). | **Isolated & Under Review.** Lazy-chunk isolation is verified by Playwright metrics, though `/search` still uses zero InstantSearch facet widgets. | Re-evaluate vs. `useInfiniteQuery` if InstantSearch facet widgets are not adopted later. |
| **Facade Hooks + Granular Subscriptions** | Deliberate | `apps/storefront/src/hooks/{useCart,useCurrency,useTheme,useFavorites,useProducts,useRecommendations,useSearch,useDevChaos}.ts` | Hides Redux, TanStack Query, theme storage, and DEV chaos behind domain hooks while isolating component re-renders (`useCartActions`, `useCartBadge`, `useCartItemState`). | **Consistent & Enforced.** All add-only surfaces (`ProductCard`, `PLP`, `PDP`, `SearchResultsPage`) consume `useCartActions()`, and Oxlint blocks direct `store/slices/*` and `infrastructure/*` imports from UI layers. | Requires keeping facade exports synchronized when adding new slice selectors or actions. |
| **Memoized Derived State (`createSelector` + `React.memo`)** | Deliberate | `apps/storefront/src/store/selectors/cartSelectors.ts`, `apps/storefront/src/pages/CartPage/components/*` | Avoids recomputing cart subtotal/discount/shipping/total and prevents sibling re-renders while typing notes, editing quantities, or applying coupons. | **Verified & Justified.** Proven by Reselect `.recomputations()` assertions (`cartSelectors.test.ts`) and React `<Profiler>` budgets (`CartPage.profiler.test.tsx`). | Adds subcomponent boilerplate; keep strictly for high-churn interactive views like Cart. |
| **Listener Middleware Side-Effect Decoupling** | Deliberate | `apps/storefront/src/store/index.ts`, `slices/{cartSlice,currencySlice}.ts`, `persistence/{cartStorage,currencyStorage}.ts` | Keeps both `cartSlice` (frozen) and `currencySlice` 100% pure while persisting versioned cart items (including `applyCartQuote` repricing), debounced checkout prefs (`pagehide` flush), and currency preference to `localStorage`. | **Consistent Across All Slices.** Hydration happens in `createAppStore()`; zero `localStorage` calls exist inside any reducer. | Requires listener registration whenever a new persisted slice or action is introduced. |
| **External Store Subscription (`useSyncExternalStore`)** | Deliberate | `apps/storefront/src/hooks/useTheme.ts`, `apps/storefront/index.html` | Synchronizes `ThemePreference` (`system \| light \| dark`), `localStorage['minieshop_theme']`, `html[data-theme]`, and live `prefers-color-scheme` media query events across components with zero FOUC (`ADR-0024`). | **Strong & Tested.** Composite `${preference}:${resolvedTheme}` snapshot triggers updates on OS theme changes while guarding against stale events after explicit user selection. | Relies on synchronous inline `<head>` script staying aligned with `THEME_STORAGE_KEY`. |
| **Two-Tier CSS-First Semantic Design Tokens (`light-dark()`)** | Deliberate | `apps/storefront/src/index.css`, `apps/storefront/src/utils/cn.ts` | Replaces 18 hand-written legacy CSS files with Tailwind CSS v4 (`@tailwindcss/vite`) and native `light-dark()` tokens exposed via `@theme inline`, reducing production CSS by 48% (`ADR-0024`). | **Strong & Ready for Phase 8.** Single styling engine with zero `@layer legacy`, dark-adaptive skeletons, and explicit `Baseline 2024+` target (`Chrome 123+`, `Safari 17.5+`, `Firefox 128+`). | Browsers older than Baseline 2024 are explicitly out of scope. |
| **Optimistic UI with Concurrency Queue Projection** | Deliberate | `apps/storefront/src/hooks/useFavorites.ts` (`WeakMap<QueryClient, FavoriteChanges>` + `scope: { id: 'favorites' }`) | Eliminates optimistic rollback race conditions when users click favorite toggles rapidly across overlapping network requests. | **Smart & Justified.** Cleanly separates confirmed server state from pending toggle queue and invalidates only once the queue drains. | Module-level `WeakMap` state is non-obvious; covered by optimistic rollback tests and Playwright metrics. |
| **Adjusting State During Render** | Deliberate | `ProductImage.tsx`, `useCombobox.ts`, `CatalogFilters.tsx`, `SearchBar.tsx`, `SearchResultsPage.tsx` | Synchronously resets derived local state when props or URL parameters change without triggering an extra `useEffect` paint cycle. | **Clean in `ProductImage`/`useCombobox`; symptomatic in `SearchResultsPage`.** Tracking 4 `prev*` states in `SearchResultsPage` compensates for InstantSearch's internal async status transitions. | Avoids effect flicker, but multi-field render-time `setState` increases cognitive load. |
| **Controlled / Uncontrolled Hybrid Inputs** | Deliberate | `Dropdown.tsx`, `CatalogFilters.tsx`, `CartItemRow.tsx` | Allows immediate local typing, debouncing, or draft validation before committing changes to URL params or Redux. | **Justified.** Draft edits clamp and validate cleanly with visible inset `focus-visible` outlines. | Requires careful timer cleanup on external resets (e.g., Clear All or currency switch). |
| **Lazy Code Splitting + `<Suspense>` + `<ErrorBoundary>`** | Deliberate | `apps/storefront/src/App.tsx` (`LazySearchRoute`), `apps/storefront/src/components/ErrorBoundary/ErrorBoundary.tsx`, `RootLayout.tsx` (`ApiDebugFab`) | Keeps `react-instantsearch` (~188 kB raw / ~52 kB gzip) and dev-only chaos UI out of initial catalog/PDP bundles while providing recoverable fault and chunk-load retry boundaries. | **Complete & Verified.** `ErrorBoundary` uses `getDerivedStateFromProps` (`resetKey`) so healthy route children never remount on navigation. | Requires preserving explicit fallback UI when adding new lazy routes. |
| **Layout Route (`<Outlet />`) & Key-Based Reset** | Deliberate | `apps/storefront/src/App.tsx`, `RootLayout.tsx`, `ProductDetailPage.tsx` (`<PdpRecommendationsSection key={product.slug} />`) | Shares persistent chrome (`Navbar`, Skip Link, single `<main id="main-content">`, footer, `MiniCart`) across routes and resets latched `useInView` state on PDP-to-PDP navigation. | **Clean & Semantically Sound.** Verified by full `RootLayout` `vitest-axe` integration tests (zero nested `<main>` landmarks). | Every new page must render a `<div>`/`<section>` root rather than `<main>`. |
| **Latched Viewport Lazy Loading (`IntersectionObserver`)** | Deliberate | `apps/storefront/src/hooks/useInView.ts`, `apps/storefront/src/pages/ProductDetailPage/components/PdpRecommendationsSection.tsx` | Defers PDP recommendation API calls until the user approaches the full-width section below the PDP grid (`rootMargin: '200px 0px'`, `ADR-0021`). | **Verified & Effective.** Achieves `CLS = 0` (`clsOnPdpAfterRecs: 0`) and full-width (`1232px`) rendering below the 2-column PDP layout. | Requires deterministic `IntersectionObserver` stubbing in jsdom tests (`src/test/intersectionObserverMock.ts`). |
| **CSRF Token Bootstrap, Caching & Abortable Single Retry** | Deliberate | `apps/storefront/src/infrastructure/http/httpClient.ts` (`awaitWithAbortSignal`) | Keeps state-changing storefront requests (`/favorites`, `/pricing/quote`) compatible with authenticated backend CSRF protection (`ADR-0014`) without breaking caller cancellation. | **Strong & Tested.** Deduplicates concurrent `GET /auth/csrf` refreshes while letting individual callers abort immediately. | Adds one bootstrap round-trip on the first mutating request per session. |

## 2. Backend & Distributed Systems Design Patterns (`apps/api`)

| Pattern | Status | Location | Problem Solved | Assessment | Trade-offs |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Modular Monolith with Barrel & Per-Schema Boundaries** | Deliberate | `apps/api/src/modules/{catalog,identity,media,platform,recommendations,search}/index.ts`, `apps/api/eslint.config.mjs` | Enforces domain barrel boundaries and per-module Drizzle schema ownership inside one deployable Node process (`ADR-0002`, `ADR-0023`). | **Strong & Sealed.** Both cross-module deep imports and cross-schema Drizzle imports under `src/database/schema/*` fail ESLint and build. | Shared deploy/runtime blast radius until extraction triggers in `ADR-0002` are hit. |
| **Database-per-Module Schema Isolation** | Deliberate | `apps/api/src/database/schema/{catalog,identity,inventory,media,platform,recommendations}.ts`, `apps/api/drizzle/*.sql` | Isolates persistence ownership across 6 PostgreSQL schemas inside a single PG17 instance while keeping local ACID transactions (`ADR-0006`). | **Clean & Enforced.** `CatalogService.linkProductImage` owns `catalog.product_images` writes; `MediaService` owns `media.*` only. | Maintaining read projections (`products.in_stock`) requires explicit sync discipline. |
| **Ports & Adapters (Hexagonal)** | Deliberate | `search.port.ts` -> `MeilisearchAdapter`; `embedding.port.ts` -> `OllamaEmbeddingProvider` / `DeterministicFakeEmbeddingProvider`; `mail-transport.ts` -> `Smtp`/`Resend`/`InMemory`; `rate-limiter.ts` -> `InMemoryRateLimiter`; `s3-storage.adapter.ts`; `clock.ts` | Isolates domain services from external infrastructure (Meilisearch, Ollama, SeaweedFS/S3, SMTP/Resend, system clock) so CI/tests run deterministically and providers stay swappable. | **Very Strong.** Clean NestJS DI tokens (`SEARCH_PORT`, `EMBEDDING_PROVIDER`, `MAIL_TRANSPORT_TOKEN`, `RATE_LIMITER_TOKEN`, `CLOCK_TOKEN`) enable fast test fakes without monkey-patching. | Adds interface/token wiring boilerplate; justified wherever external I/O or time is involved. |
| **Transactional Outbox + Polling Worker** | Deliberate | `apps/api/src/modules/platform/outbox.service.ts`, `outbox-events.ts`, `apps/api/src/modules/search/embeddings.handler.ts`, `apps/api/src/worker/main.ts`, `worker.runner.ts` | Guarantees reliable async propagation of catalog, embedding, recommendation, and email events without dual-write loss or external brokers (`ADR-0012`). | **Production-Grade & Atomic.** Uses `FOR UPDATE SKIP LOCKED`, leases, per-consumer fan-out rows, exponential backoff + jitter, and atomic embedding upsert + outbox enqueue transactions. | Polling adds small eventual-consistency lag (`500ms` default) and requires retention cleanup (`OUTBOX_RETENTION_DAYS`). |
| **Circuit Breaker + Multi-Tier Graceful Degradation** | Deliberate | `apps/api/src/modules/search/circuit-breaker.ts`, `search.service.ts`, `apps/api/src/modules/recommendations/relations.service.ts` | Keeps storefront search (including `?currency=` price-bound conversion + post-hydration filtering) and recommendations available (`HTTP 200`) even when Ollama or Meilisearch is slow or down (`ADR-0010`, `ADR-0013`). | **Strong & Tested.** Search degrades `hybrid` -> `keyword` -> `postgres` (3 failures / 15s open window); recommendations degrade from `pgvector` kNN to deterministic rules. | In-memory circuit breaker state is per API replica (acceptable at single-instance/small scale). |
| **TTL LRU Cache** | Deliberate | `apps/api/src/modules/search/lru-cache.ts`, `apps/api/src/modules/search/search.service.ts` | Caches query embedding vectors (`256` entries, `5 min` TTL) to avoid repeating CPU Ollama inference for repeated searches. | **Well-Scoped & Simple.** Zero external dependency (no Redis required). | Per-process memory cache; not shared across multiple API replicas. |
| **Content-Hash Idempotency & Deduplication** | Deliberate | `apps/api/src/modules/search/embedding-text.ts` (`computeEmbeddingContentHash`), `apps/api/src/modules/media/media.service.ts` (`checksumSha256`) | Prevents redundant embedding inference when non-indexed fields change (`ADR-0011`, `ADR-0022`) and deduplicates identical uploaded media binaries. | **Effective.** Changing embedding template version or model cleanly forces recomputation via hash mismatch. | Media dedupe short-circuits `status === 'ready'`; failed checksum retries require cleanup. |
| **Zero-Downtime Shadow Index Swap** | Deliberate | `apps/api/src/modules/search/meilisearch.adapter.ts` (`reindex`) | Rebuilds the Meilisearch `products` index into a temporary index and performs an atomic `/swap-indexes` with zero search downtime. | **Verified.** Idempotency verified automatically in `pnpm search:eval` (`docs/metrics/search-relevance.md`). | Temporarily doubles Meilisearch index storage during full reindex. |
| **Advisory-Lock Job Coordination** | Deliberate | `apps/api/src/modules/identity/session.service.ts` (`pg_try_advisory_xact_lock`), `apps/api/src/worker/main.ts` | Prevents concurrent worker replicas from running overlapping `cleanupExpiredSessions()` sweeps. | **Clean & Lightweight.** Uses native PostgreSQL advisory locks without extra scheduler infrastructure. | Requires maintaining a unique numeric lock key per scheduled job. |
| **Deny-by-Default Guard + Metadata Decorators** | Deliberate | `apps/api/src/modules/identity/identity.guard.ts`, `decorators.ts`, `staff-admin.service.ts`, `staff-admin.controller.ts` | Enforces dual-cookie principal resolution, Origin + HMAC CSRF protection, customer auth, deny-by-default RBAC across `/admin/*`, and active-only (`isActive = true`) last-admin invariants (`ADR-0014`). | **Strong & Tested.** Reflection-based tests (`staff-rbac.integration.spec.ts`) prove every `/admin/*` route declares explicit auth metadata, and storefront `HttpClient` handles CSRF seamlessly. | Global `APP_GUARD` makes opt-out explicit (`@SkipCsrf`, `@PublicAdminRoute`), which is safer than opt-in. |
| **Global Exception Filter + Masked Contract Output Validation** | Deliberate | `apps/api/src/common/global-exception.filter.ts`, `apps/api/src/common/errors.ts`, `apps/api/src/common/parse-response.ts`, `apps/api/src/health/health.controller.ts` | Normalizes all API errors into `{ error: { code, message, details?, requestId } }` (`ADR-0008`) while masking internal 500 `parseOutput` Zod details server-side. | **Consistent & Hardened.** Raw `parseOutput` schema errors are logged server-side and returned to clients as generic `500 INTERNAL_ERROR` envelopes across all controllers including `HealthController`. | Requires checking server logs with `requestId` when debugging contract mismatches. |
| **Conditional HTTP Caching (Weak ETag)** | Deliberate | `apps/api/src/common/http-cache.ts`, `apps/api/src/app.factory.ts` | Cuts redundant payload transfers on public catalog/search/recommendation GETs (`W/"..."` + `304`, `max-age=30`) while enforcing `no-store` on `/favorites`, `/auth`, `/me`, `/admin`. | **Effective.** Minor HTTP spec limitation: `ifNoneMatch.trim() === etag` does not parse comma-separated ETag lists or `*`. | Hash computed over serialized payload per request (fast for small catalog JSON responses). |
| **Keyset (Cursor) Pagination & Disjunctive Faceting** | Deliberate | `apps/api/src/modules/catalog/catalog-query.ts`, `catalog-filters.ts`, `catalog.service.ts` | Provides stable pagination under concurrent catalog updates (currency-scoped cursor) and accurate multi-select facet counts without hiding sibling options (`ADR-0017`, `ADR-0018`). | **Solid.** Eliminates offset drift and keeps filter counts intuitive. | Cannot jump directly to arbitrary page N; requires `FacetsDTO` root-count summation for total display on PLP. |
| **Pure Domain Rule Engine** | Deliberate | `apps/api/src/modules/recommendations/relations-rules.ts` | Keeps rule-based related/upsell scoring, round-robin cross-sell category diversity, and manual-before-auto sorting pure and framework-free. | **Clean & Well-Tested.** Covered directly by fast unit tests (`relations-rules.test.ts`) with zero DB/Nest dependencies. | Must stay synchronized with SQL pre-filtering bounds in `CatalogService`. |

## 3. Cross-Cutting & Contract Patterns (`packages/*` & Monorepo)

| Pattern | Status | Location | Problem Solved | Assessment | Trade-offs |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Strict-Server / Tolerant-Client Schema Duality** | Deliberate | `packages/contracts/src/{catalog,search,recommendations,identity}/{public,client}.ts`, `apps/api/src/common/parse-response.ts`, `apps/storefront/src/infrastructure/http/httpClient.ts` | Fails closed on server DTO leaks (`.strict()`) while allowing additive API fields without breaking deployed browsers (`.strip()`) (`ADR-0008`, `ADR-0017`, `ADR-0023`). | **Signature Strength — Complete.** All four domains (`catalog`, `search`, `recommendations`, `identity`) expose `.strip()` client subpaths; backend-internal `searchIndexDocumentSchema` lives exclusively inside `apps/api`; exports are gated by `publint --strict` and unit tests. | Manual schema parity between `public.ts` and `client.ts` is guarded by `packages/contracts/src/contracts.test.ts`. |
| **Stack-Pinned Config Presets (`@minieshop/config`)** | Deliberate | `packages/config/{tsconfig.base,tsconfig.node,tsconfig.web}.json`, `eslint.base.mjs`, `prettier.json` | Allows NestJS/Drizzle Node packages (`typescript 5.9.3`) and the React 19 + Vite 8 storefront (`typescript 7.0.2`) to share strict compiler and formatting standards cleanly (`ADR-0023`). | **Clean & Verified.** Every workspace package extends presets by package name (`@minieshop/config/*`), with zero relative `../../` config hops. | Must keep `tsconfig.base.json` limited to options valid in both TS 5.9 and TS 7.0. |
| **Fail-Fast Boot Env Validation** | Deliberate | `apps/api/src/config/env.ts`, `apps/storefront/src/config/env.ts` | Rejects missing/malformed env vars and unsafe production defaults (`COOKIE_SECURE=false`, dev secrets, `CHAOS_ENABLED=true`) before serving traffic. | **Strong & Verified.** Tested in unit tests on both backend and storefront. | Requires keeping `.env.example`, `infra/compose.yaml`, and Zod schemas aligned. |
| **Dual-Implementation Contract Test Suite** | Deliberate | `apps/storefront/src/infrastructure/repositories/productRepositoryContract.test.ts` | Verifies behavioral parity between `MockProductRepository` and `HttpProductRepository` (routed through `HttpClient` + `.strip()` schemas). | **High Leverage.** Prevents test mocks from silently diverging from HTTP client parsing/serialization. | Does not run against live NestJS controllers (backend integration specs cover the server side separately). |
| **Build-Time Tree-Shaken Chaos Injection** | Deliberate | `apps/storefront/src/infrastructure/http/chaos.ts`, `apps/storefront/src/hooks/useDevChaos.ts`, `apps/api/src/common/chaos.middleware.ts`, `ApiDebugFab.tsx` | Enables controlled latency and error testing in DEV/Playwright metrics with zero chaos code in production bundles (`docs/chaos-dev-guide.md`). | **Well-Engineered.** API refuses boot if `NODE_ENV=production` and `CHAOS_ENABLED=true`; storefront verifies zero `x-chaos-*` strings in `dist/`. | Relies on Vite `import.meta.env.DEV`; will need a framework-agnostic guard if shared with Next.js. |

## 4. Notable Pattern Absences & Conscious Non-Adoptions

| Pattern | Current State | Rationale / Action |
| :--- | :--- | :--- |
| **Compound Components & Render Slots** | **Deferred to Phase 8** | Current components (`Dropdown`, `MiniCart`, `RecommendationCarousel`, PDP Tabs) are prop-driven. Intentionally deferred until Phase 8 Design System extraction (`@minieshop/ui`). |
| **Separate Frontend Domain Entity Model** | **Conscious Simplification** | Storefront consumes `@minieshop/contracts` DTOs directly rather than mapping DTO -> Entity -> ViewModel. Appropriate at current complexity; revisit only if UI models diverge heavily from API shapes. |
| **Dedicated Message Broker / Redis** | **Conscious Non-Adoption** | Replaced by PostgreSQL `platform.outbox_events` (`ADR-0012`) and `InMemoryRateLimiter` (`ADR-0014`) to keep local infra minimal and zero-cost until multi-replica scale demands it. |

## 5. Pattern Maintenance Checklist ("As We Go")

Before merging any feature, refactor, or ADR change, verify:
1. **New pattern introduced?** Add a row with status, exact file paths, problem solved, honest assessment, and trade-offs.
2. **Existing gap resolved?** Update the corresponding row immediately.
3. **Pattern retired?** Remove or mark it as retired so this file always reflects live repository reality rather than historical intent.
4. **ADR created or superseded?** Cross-reference the ADR number in the row description.
