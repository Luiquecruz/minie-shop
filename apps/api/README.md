# `@minieshop/api`

Backend monolito modular do Progressive Minie Shop (NestJS + Fastify + Drizzle ORM + PostgreSQL + SeaweedFS).

> **Nota de Monorepo:** durante a Fase 1, `apps/api` e `packages/contracts` possuem `package.json` e `pnpm-lock.yaml` independentes e utilizam dependências locais via `link:` para manter o SPA e o lockfile da raiz intocados. A unificação em workspace `pnpm` na raiz ocorrerá na **T20**.
